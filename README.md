# 🚀 **Smart AI Analyzer** 🚀

An all-in-one, intelligent platform powered by **Google Gemini AI** and **Streamlit** to analyze, optimize, and build resumes. It assesses resumes against targeted job roles, calculates ATS scores, highlights missing keywords, suggests courses, and provides structured feedback to help candidates land their dream jobs.

---

## 🌟 **Key Features**

*   🔍 **AI-Powered Resume Analysis**: Instant ATS scoring, readability evaluation, and detailed formatting critiques.
*   📝 **Smart Resume Builder**: Easy-to-use form to generate professional, ATS-optimized resumes with modern templates.
*   📊 **Analytics Dashboard**: Dynamic metrics showing resume upload histories, score distributions, and career progress metrics.
*   🎯 **Role-Based Suggestions**: Tailored keyword matching and skill enhancement suggestions for specific job categories (e.g., Software Engineering, Data Science, Product Management).
*   💡 **Resource Recommendation**: Auto-suggests courses and video playlists based on identified skill gaps.
*   💬 **Feedback Portal**: A feedback form with responsive rating trackers and real-time visualization of community suggestions.

## 🚀 **Quick Start**

### 1. Clone & Initialize
```bash
git clone https://github.com/Karankumar2403/Smart-AI-Analyzer.git
cd Smart-AI-Analyzer
```

### 2. Install Dependencies
```bash
pip install -r requirements.txt
```

### 3. Setup Gemini API Key
Create a `.env` file in the root directory:
```env
GEMINI_API_KEY=your_gemini_api_key_here
```

### 4. Run the Application
```bash
python run_app.py
```
Or start via Streamlit directly:
```bash
streamlit run app.py
```

## 🛠️ **Technologies Used**

*   **Frontend**: Streamlit, HTML5, Custom CSS3, Lottie Animations
*   **AI Engine**: Google Gemini AI (Generative AI API)
*   **Data Analysis & DB**: SQLite3, Pandas, Plotly Express
*   **Document Parsers**: pdfminer.six, docx2txt, PyPDF2
